This section discusses signal Monte Carlo (MC), background MC and data samples.
For completeness the correspondence between decay mode and Monte Carlo numbers
is given in the following list for signal-like decays:
\begin{itemize}
\item 208445:  \MCsigFlat: This sample of MC has $F_L$=1/3.
\item 208446:  \MCsigSM
\item 208447:  \MCsigBarSM
\item 208439:  \MCsigBad. Note that this sample of MC has a biased \qsqr distribution (piled up at very low values) and is of very limited use.
\item 208448:  \MCBdKstJpsi
\item 208449:  \MCBdKstPsiTwoS
\item 208451:  \MCswave
\end{itemize}
The following exclusive backgrounds have been studied:
\begin{itemize}
\item 208400: \MCBsJpsiPhi
\item 208404: \MCLambdabLambdaJpsi
\item 208405: \MCAntiLambdabLambdaJpsi
\item 208412: \MCBdJpsiKS
\item 208423: \MCBdPsiTwoSKS
\item 208424: \MCLambdabLambdaPsiTwoS
\item 208425: \MCAntiLambdabLambdaPsiTwoS
\item 208430: \MCBuJpsiKplus
\item 208432: \MCBuJpsiPi
\item 208436: \MCBuJpsiKminus
\item 208440: \MCBuKstmm ($K^{*+}\to K^0\pi^+$).  Note that the $K^0$ is not forced to decay, so it is a superposition of $K_S$ and $K_L$ and the $K^*$ decay contributes a Clebsch-Gordon coefficient factor of 2/3 on the decay rate.  A separate sample with $K^*+\to K^+\pi^0$ is under study with a CG factor of 1/3.
\item 208441: \MCBsPhimm
\item 208450: \MCBuKmm
\item 208452: \MCBsJpsiKst
\item 208455: \MCBdPhiKst
\item 208456: \MCLambdabLambdaMuMu
\item 208457: \MCLambdabKPMuMu
\end{itemize}
